# 苹果主屏与私人 App 系统栏稳定基线 v950

确认日期：2026-08-16

确认状态：用户已在真机确认私人 App 底部黑条修复成功。以后涉及 viewport、safe area、主屏幕 Web App、状态栏或 Home 指示条的修改，必须以本文件为基线。

## 成功方案

- 网页保留当前网址和全部新功能，只恢复 v600 的外壳契约。
- 不使用动态系统栏取色、强制 34px 底部安全区、负 bottom、屏幕外拉伸或全局 100dvh。
- 私人 App 顶部安全区由 iOS 管理并保持纯黑色。
- 私人 App 的 WKWebView 继续覆盖 Home 指示条区域，必须保留 `.ignoresSafeArea(.container, edges: .bottom)`。
- 电话头像、名称、接通时间和字幕属于网页版公共布局，苹果与安卓共同生效；私人 App 电话布局保持原样。

## 无按钮的苹果自动适配

- 设置页不再出现“苹果兼容适配”。
- 仅真实 iPhone／iPad 且处于主屏幕 standalone Web App 时，自动添加 `north-ios-home-safe` 与 `north-apple-remote-safe`。
- Android、普通 Safari 和私人 WKWebView 不添加这些类。
- 旧存档中的 `appleHomeCompat` 值仅作为历史数据保留，不再控制布局。

## 安装与缓存

- 新用户直接从当前正式网址添加到主屏幕，不需要旧网址。
- 安装过故障外壳的用户，为排除 iOS 保存的旧安装状态，只需删除主屏幕图标并重新添加一次。
- 后续正常功能更新不得再次改变本基线，因此不应要求用户反复重新添加。

## 禁止恢复

- `viewport-fit=cover`
- 动态底栏颜色采样或主题色同步
- 强制 `34px` 底部安全区
- 负 `bottom` 或向物理屏幕外延伸
- 用整份旧网页覆盖当前网页
- 删除私人 App 的原生底部覆盖行

## 必测边界

1. iPhone 主屏幕 Web App 顶部控件可点击，底部不因网页补偿而继续变宽。
2. Android 不出现苹果顶部位移。
3. 私人 App 顶部保持黑色系统栏，底部没有整块黑色空白。
4. 微信、音乐、电话、宠物、屏保和主屏拖拽无回归。

# 小手机

当前基线：网页核心 v944／私人 iOS 1.0.68 (68)／原生桥契约 18。本版先处理云端授权事故的客户端止损：原生刷新遇到临时 401、超时或网关异常时保留 Keychain 登录，不再把手机号误显示成未绑定；网页授权检查对临时故障静默退避，只有明确的封禁、授权不存在或本机身份损坏才退出；音色列表读取失败时显示该账号上次成功读取的缓存，但实际发声仍由服务器验证归属。已经在事故期间被旧版清掉登录的设备无法凭空恢复密码，需等云端恢复后用原手机号和密码重新登录。v943 伴生日常与低电提醒、v942 音乐布局、v941 通话输入、v938 第二页组件继续保留；Android、主页拖拽以及 iPhone 主屏幕 Web App 的系统底栏均未改动。维护与真机验收边界见 `docs/maintenance/私人小手机App_唯一总纲.md`。

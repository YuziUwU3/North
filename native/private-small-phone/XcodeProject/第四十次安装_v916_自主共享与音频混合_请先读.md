# 小手机私人版 v916 / 1.0.40（40）

本次只使用这一份工程。压缩包已经排除历次“第×次安装”说明，避免再次混入一大堆旧安装文件。

本版重点：

- 屏幕共享不再每 4 秒强制识别。角色看完一帧后自行选择继续观察、暂停提问、等待你切换页面或结束观察；只有角色明确选择继续，才会安排下一次取帧。
- 角色说“请打开另一个页面”后会暂停；你说“打开了、切好了、给你看”才读取新画面。口头要求“你看一下”仍不受自动次数限制。
- 外部视频/音乐播放时，通话录音、角色语音和系统悬浮字幕改用混音会话，减少彼此抢占。
- 屏幕识别提示明确忽略小手机自己的通话悬浮框，避免把角色自己的字幕或头像当作外部内容。
- 通话字幕改回逐字浅入、轻微上浮的自然动画；语音识别增加纠错等待时间，再把最终句发送给角色。
- 音乐搜索增加 Apple 中国区官方曲库试听，与 Audius 公共全曲并行；不要求登录。
- 角色作息会按真实工作时段推进共同生活状态；关闭时间感知后不会读取或推断作息和时间。
- 宠物自然成长只前进不后退；只有手动“退化回奶团期”才会变小。

## 只做三个操作

1. 在 Mac 解压后，双击 `PhoneCompanionTest.xcodeproj`。
2. Xcode 顶部运行目标选 `PhoneCompanionTest`，设备选你已连接的真实 iPhone；不要选 `Any iOS Device`、Report、Monitor、Shield 或扩展。
3. 点运行安装，进入视频通话，打开“实时共享理解（测试）”和屏幕共享后验证。

## 这次重点实机验证

- 角色选择暂停提问后，右下角转圈应停止；回答后由角色决定是否继续。
- 角色要求切页时，在你说“切好了”之前不得继续取帧。
- 播放抖音或音乐时，话筒和角色语音能否同时保留。
- 共享外部 App 后，识别内容不能仍是小手机通话页或悬浮字幕。

Windows 已完成 JavaScript 语法检查和 545 项自动回归；Windows 不能替代 Mac 的 Xcode 全 Target 编译、签名和真实 iPhone 音频/ReplayKit 验收。

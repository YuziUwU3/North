# 第七十九次安装：v957 网易云官方播放器接入

当前候选版本：

- 网页核心：v957
- 私人 iOS：1.0.79 (79)
- 原生桥：18

本次只新增网易云官方外链播放器并保留现有音乐链路：

1. 音乐首页新增“网易云”，在线搜索页也有网易云入口。
2. 支持粘贴 `music.163.com` 的歌曲、专辑或歌单完整链接；歌曲也可直接填写数字 ID。
3. 播放器使用 `https://music.163.com/outchain/player`，最近打开的八条记录只保存在小手机本机。
4. 私人 WKWebView 只放行该网易云官方子框架；其他远程导航继续交给 iOS 打开。
5. Apple 中国区官方试听、Audius 公开曲库、本地 MP3/M4A、导入导出和一起听全部保留。
6. 本版不保存网易云账号、不抓取或下载网易云音源、不解灰，也不绕过会员、版权或 DRM 限制。

Windows 已验证网易云链接解析、来源白名单、官方播放器真实加载和原音乐专项；完整自动回归 665/665 通过。这里没有 Mac，不能把该结果写成 Xcode 编译、签名或真实 iPhone 通过。

Mac 与真机验收顺序：

1. 从全新目录 `SmallPhone_v957_NeteaseOfficialPlayer` 打开工程，全 Target 编译 1.0.79 (79)，不要从旧 ZIP 覆盖 `PhoneWeb.bundle`。
2. 设置页顶部确认显示 v957 和私人安装包 1.0.79 (79)。
3. 打开音乐首页，确认“网易云”入口存在；粘贴一条 `music.163.com/#/song?id=...` 完整链接。
4. 确认网易云官方播放器留在小手机内，歌曲封面、歌名、歌手和播放键正常显示；受限歌曲应按网易云官方提示处理。
5. 返回后重新打开最近记录，并检查 Apple 试听、Audius、本地 MP3/M4A、导入导出和一起听没有回归。
6. 在 Android 网页重复步骤 3～5，确认外链播放器和返回操作正常。

若任一步失败，保留截图、歌曲链接、设备型号、系统版本和准确操作顺序，不要同时改变多个变量。

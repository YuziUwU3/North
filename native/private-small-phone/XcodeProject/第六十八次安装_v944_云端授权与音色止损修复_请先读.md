# 第六十八次安装：v944 云端授权与音色止损修复

- 网页核心：v944
- 私人 iOS：1.0.68 (68)
- 原生桥契约：18
- 必须完整解压本次 ZIP，只从全新目录 `SmallPhone_v944_CloudAuthContainment` 打开 `PhoneCompanionTest.xcodeproj`，不要覆盖旧工程。

## 本次止损

1. 原生账号刷新遇到临时 401、连接超时或网关错误时保留 Keychain 登录，不再把短暂云端事故当成退出登录。
2. 网页授权检查对临时故障静默指数退避，最长 30 分钟；只有明确的封禁、授权不存在或本机身份损坏才显示授权页。
3. 音色列表读取失败时显示当前账号上次成功读取的缓存，避免短暂故障时界面看起来全部丢失。
4. 音色缓存只保存有限的显示字段；真正合成语音时仍由服务器检查账号与音色归属，不能用缓存绕过授权。
5. 用户主动退出仍会正常清理本机登录。事故期间若已被旧版清掉登录，本版无法凭空恢复密码，需等云端恢复后用原手机号和密码重新登录。

## 编译与验收

1. 解压后打开 `PhoneCompanionTest.xcodeproj`，选择 `PhoneCompanionTest` Scheme 与真实 iPhone。
2. 执行 `Product → Clean Build Folder`，再编译安装。
3. 设置页顶部必须显示“当前已加载：v944 · 云端授权与音色止损修复”和“私人安装包 1.0.68 (68)”。
4. 正常登录后模拟断网、超时或临时 401，再重启和切换前后台：手机号登录应保留，不应反复弹授权失败，也不应跳邀请码页。
5. 云端不可用时，已成功读取过音色的账号应能看到上次音色列表；恢复网络后应自动以云端最新列表覆盖缓存。
6. 恢复后分别验证绑定手机号、授权、克隆音色播放和主动退出；另一个账号不得通过缓存使用不属于自己的音色。
7. Windows 自动测试和静态检查不能代替 Mac 编译、签名与真实 iPhone 验收。

# 第六十六次安装：v942 音乐键盘与唱片布局修复

- 网页核心：v942
- 私人 iOS：1.0.66 (66)
- 原生桥契约：18
- 必须完整解压本次 ZIP，只从全新目录 `SmallPhone_v942_MusicKeyboardLayout` 打开 `PhoneCompanionTest.xcodeproj`，不要覆盖旧工程。

## 本次变化

1. 仅在苹果兼容模式的音乐输入框聚焦时，把聊天栏一次性滚到键盘上沿；键盘视口变化时保持贴合，不恢复旧的三次整页回弹。
2. 一起听的距离与累计时长从临时气泡预留区后面移到头像结束键正下方，空气泡不再把文字顶远。
3. 音乐发送键增强白色玻璃折射、顶边高光与内外阴影；粉色结束键保留识别色并增加玻璃层次。
4. 唱片外径保持不变，中心封面由内缩 38px 扩大为 30px，图片更醒目但不挤压唱片外圈。
5. Android 不命中苹果键盘定位规则；没有改动主页、第二页、拖拽、通话页或 iPhone 主屏幕系统底栏。

## 编译与验收

1. 解压后打开 `PhoneCompanionTest.xcodeproj`，选择 `PhoneCompanionTest` Scheme 与真实 iPhone。
2. 先执行 `Product → Clean Build Folder`，再编译安装。
3. 设置页顶部必须显示“当前已加载：v942 · 音乐键盘与唱片布局修复”和“私人安装包 1.0.66 (66)”。
4. 在私人 iPhone 打开音乐播放器并点输入框：页面应自动到最底部，聊天胶囊贴在系统键盘上沿；连续打开／收起键盘三次，不应需要手动滑动，也不应上下弹跳。
5. 一起听时确认距离／时长紧跟粉色结束键下方；歌曲气泡出现和消失不能再改变这行文字的位置。
6. 确认发送键是白色高光玻璃，结束键保留粉色但有高光折射，唱片中心图片扩大且外圈尺寸不变。
7. 用安卓网页复核音乐输入、主页拖动和应用显示没有套用苹果键盘定位规则。
8. Windows 自动测试和静态检查不能代替 Mac 编译、签名及真实 iPhone／Android 的键盘和触摸验收。

# 第九十一次安装：v969 Xcode 编译与人声增益修复

- 网页核心：v969
- 私人 iOS：1.0.91 (91)
- 原生桥：23

请不要再使用第九十次安装的 v968 压缩包。该包中的共享媒体人声增益误用了不存在的 `AVAudioUnitDynamicsProcessor`，会在 Xcode 中直接编译失败；v969 已改用公开的 `AVAudioUnitEQ.globalGain`，并移除了会触发 Swift 6 并发捕获错误的播放器完成闭包。

安装时必须完整解压到全新目录 `SmallPhone_v969_NativeBuildVoiceGain`，不要覆盖任何旧工程。用 Xcode 打开 `PhoneCompanionTest.xcodeproj`，先执行 `Product → Clean Build Folder`，再选择 `PhoneCompanionTest` Scheme 和真实 iPhone 编译安装。设置页应显示 v969 与 1.0.91 (91)。

本次保留 v968 已完成的全部功能：屏幕共享开始／结束带真实通话上下文且最多重试一次；外语台词保留逐句中文翻译；角色手机日记独立密码、输错一次被发现、按需生成当天一篇、未收藏 24 小时后消失、收藏永久保留；通话内容默认折叠；修改自己的微信备注后角色在下一次真实聊天发现；角色推特结合真实日常并使用宽松去重。微信主动联系与通话静默后的主动说话还会把上一轮明确标记为已经回复完成，从角色自己上一句往后继续话题，不会重新回答用户已经得到回应的旧句。电话接通与结束事件会明确记录是谁主动拨打、谁接听、谁主动挂断，并携带本通电话最近内容生成自然反应，双方动作不会说反；角色主动来电而用户未接时，也会作为“从未接通”的独立事件自然反应，不会误判为挂断。网页版仍只是隔离真实设备数据，没有删除原有功能。

Windows 已执行语法、资源同步、版本一致性和原生源码静态回归检查，但 Windows 不能代替 Mac 的 Xcode 编译、签名与真机音频验收。请在 Mac 上确认 Issue Navigator 没有红色编译错误，再验证后台视频与角色人声比例、扬声器／蓝牙路由及 Device Activity Report。

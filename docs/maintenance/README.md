# 项目长期维护资料

本目录中的四份 Word 文档是项目的长期记录，不是临时参考资料。

## 开发前

在分析问题或修改代码前，先完整阅读并理解：

1. `AI开发项目_项目说明文档.docx`
2. `AI开发项目_Bug修改规范.docx`
3. `AI开发项目_Bug记录模板.docx`
4. `AI开发项目_新聊天启动说明.docx`

遇到相似问题时，先检索历史记录，优先采用已经验证有效的方案，不重复已有失败尝试。

## 开发后

- 新增功能、修改方案或形成重要决策：更新《项目说明文档》。
- 遇到 Bug、完成原因排查、形成解决方案或出现失败尝试：追加到《Bug记录模板》，不得删除历史记录。
- 发现新的开发规则或容易重复踩坑的问题：更新《Bug修改规范》。
- 每次修改核心功能后：主动检查上述三份文档是否需要同步更新。

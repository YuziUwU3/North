# 小手机私人版第七十一次安装说明

## 版本

- 私人 iOS：1.0.71 (71)
- 内置网页核心：v950 · 底部外壳回退
- 原生桥契约：18

## 本次改动

- 网页和私人 App 都撤回此前围绕底部系统黑条加入的动态颜色采样、主题色同步、强制 34px 底部安全区与向屏幕外拉伸。
- 私人 App 原生容器继续让网页覆盖到底部 Home 指示条区域，避免安全区重新露出一整条黑色空白；顶部系统栏仍保持原来的黑色与高度。
- 网页版电话的已接通时间、头像、名称和字幕位置改成苹果与安卓共用，不再依赖“苹果兼容”开关。
- 私人 App 电话页面保持原布局，没有复制网页版电话位置调整。
- 既有微信、音乐、宠物、第二页组件、云端止损、授权与扫脸／指纹逻辑继续保留。

## Mac 安装步骤

1. 完整解压本次 ZIP，确认顶层目录为 `SmallPhone_v950_BottomInsetCorrection`。
2. 只打开该目录内的 `PhoneCompanionTest.xcodeproj`，不要覆盖或拖进旧工程。
3. 在 Xcode 执行 `Product → Clean Build Folder`。
4. 选择 `PhoneCompanionTest` Scheme 和真实 iPhone，确认 Team、签名与五个 Target 均正常后运行。
5. 安装后进入设置页，确认顶部显示 `v950 · 底部外壳回退` 与 `1.0.71 (71)`。

## 真机重点验收

- 私人 App 网页内容正常铺到 Home 指示条区域，不再出现整块底部黑色空白；网页自身没有额外 34px 垫高或动态染色。
- 私人 App 电话头像、名称、时间和字幕仍是原位置；网页版在苹果与安卓上使用新的统一电话位置。
- 私人 App 设置中仍没有“苹果兼容适配”和浏览器管理内容，扫脸／指纹授权可正常使用。
- 第一页锁屏箭头、微信小号记忆隔离与一次性报备、音乐、宠物、第二页和云端止损均无回归。

Windows 只能完成静态与自动化测试，最终仍须在 Mac 编译、签名并做真机验收。

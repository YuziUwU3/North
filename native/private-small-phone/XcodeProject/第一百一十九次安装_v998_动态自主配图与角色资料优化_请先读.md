# 第一百一十九次安装：v998 动态自主配图与角色资料优化

- 网页资源：v998
- 私人 iOS：1.0.119 (119)
- 原生桥：25
- 交付日期：2026-08-20

## 安装前必须确认

1. 完整解压 ZIP，并把解压后的工程文件夹单独命名为 `SmallPhone_v998_SocialImageProfile`；不要覆盖或继续编译任何旧工程。
2. 打开其中的 `PhoneCompanionTest.xcodeproj`，Xcode 选择 `PhoneCompanionTest` Scheme 和真实 iPhone，先执行 `Product → Clean Build Folder`，再运行安装。
3. 设置页底部必须显示“v998 · 动态自主配图与角色资料优化”和“私人安装包 1.0.119 (119)”；不一致时立即停止。

## 本次重点验收

1. 进入任一角色微信资料主页，右上角三个点应紧凑自然，点击后仍能打开联系人设置。
2. 开启并正确配置外置生图后，用“让角色发一条”、角色 X 主页刷新、朋友圈刷新各测一次：具体生活场景可由角色自主配图，纯心情短句可以只发文字。
3. 生图成功前不能先出现朋友圈或 X 动态；图片必须真实显示，不能留下加载失败或空白图片。
4. 临时使用错误生图模型或不可用线路验证降级：首次失败后自动重试一次，两次都失败后只发布正文，不显示坏图，也不无限重试。
5. 关闭“让角色发真照片”或清空生图配置后，角色动态不得调用生图接口，应直接安全发布纯文字。
6. 继续核对网页版不出现私人伴生入口；私人 App 的后台通知、真实设备控制和手机号账号不应泄漏到网页版。

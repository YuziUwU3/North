- 网页核心：v977
- 私人 iOS：1.0.99 (99)
- 原生桥：23

请完整解压到全新目录 `SmallPhone_v977_AllControlBoth`，不要覆盖任何旧工程。用 Xcode 打开 `PhoneCompanionTest.xcodeproj`，先执行 `Product → Clean Build Folder`，再选择 `PhoneCompanionTest` Scheme 和真实 iPhone 编译安装。设置页应显示“v977 · 内外全锁与解除修复”和“1.0.99 (99)”。

本版把角色明确说出的“全部锁定／全锁／一键全锁”固定为内外完整动作：小手机中已授权的全部内置 App 会全部锁定，真实 iPhone 当前全部已选 App 也会逐个按稳定 ID 提交。“全部解锁／解除全锁／一键全解”使用完全相同的目标范围解除。模型即使误写成“仅内置”或“仅外置”的全量标签，执行层也会先识别全量意图并阻止降级。单个和多个点名锁定、解锁保持原逻辑。

Windows 自动测试只能证明源码、内置资源和工程配置一致，不能证明 Apple 签名、Family Controls 权限、DeviceActivity 回执或真机后台运行。安装后请至少检查：全部锁定、解除全锁、全部解锁、指定单个 App、指定多个 App、操作记录、设备回执，以及关联设置在等待同步与重启后的保留情况。

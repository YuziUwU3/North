# 第六十次安装：v936 音乐完整导入与长单曲导出修复

- 网页核心：v936
- 私人 iOS：1.0.60 (60)
- 原生桥契约：18
- 必须从压缩包中的全新目录 `SmallPhone_v936_InstallVerified` 打开工程，不要覆盖任何旧安装目录。

## 本次修复

- 音乐库导入本地音频或录屏时，写入后会重新读取并核对文件大小与首尾内容，避免界面显示已导入、实际文件却不完整。
- 如果已有歌曲的本地文件丢失，提示框会让你在原歌曲上重新选择文件；歌名、封面、歌词和已经制作的歌词时间轴都会保留，不必删除歌曲重做。
- 较大的 3–4 分钟单曲会导出为 `.northmusic` 二进制文件，原音频不会再转换成 Base64，也不再受旧版 32 MB 单曲限制。
- 旧版小型 JSON 音乐包仍然可以继续导入。
- 网页版与私人 App 使用同一套 v936 音乐修复。
- 微信来电默认继续使用本次指定 MP3，并恢复“从音乐库选择来电铃声”；所选歌曲失效或删除后自动回到默认 MP3。

## 编译与核验

1. 完整解压压缩包。
2. 打开 `PhoneCompanionTest.xcodeproj`。
3. 执行 `Product → Clean Build Folder`。
4. 用 `PhoneCompanionTest` Scheme 在真机运行。
5. 设置页顶部应显示“当前已加载：v936 · 音乐完整导入与长单曲导出修复”和“私人安装包 1.0.60 (60)”。

Windows 不能替代 Mac/Xcode 的签名和真机编译。本次没有修改 iPhone 主屏幕网页底部系统区域，仍保持 v934 的处理。

# 小手机

当前基线：网页核心 v936／私人 iOS 1.0.60 (60)／原生桥契约 18。设置页会直接显示当前加载的网页核心和私人安装包版本，便于排除旧解压目录、旧 Xcode 缓存或旧安装包。iPhone 主屏幕 Web App 的系统底栏保持 v934 原处理，不再尝试消除、改色或移动网页适配。音乐库本地文件改为写入后逐字节边界校验；文件缺失时可在原歌曲上修复，不删除歌词和时间轴；较大的 3–4 分钟单曲使用不经 Base64 的二进制 `.northmusic` 包导出，避免旧版 32 MB 上限和内存峰值。微信来电默认使用用户指定 MP3，同时保留“从音乐库选择来电铃声”，所选歌曲失效时回退默认 MP3。微信底部输入栏、统一消息 MP3、双人组件、屏幕共享逐句看和仅主页第一页显示的屏保箭头继续保留。维护与真机验收边界见 `docs/maintenance/私人小手机App_唯一总纲.md`。

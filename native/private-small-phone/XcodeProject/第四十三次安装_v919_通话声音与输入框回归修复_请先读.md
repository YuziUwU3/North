# 小手机私人版 v919 / 1.0.43（43）

本次只使用这一份工程，不要混入旧版 `PhoneWeb.bundle`。

本版优先恢复普通电话和普通视频通话的角色声音。已按 v917 正常版本对照，恢复每段角色音频播放前重新激活 iOS 通话音频会话；同时把免提最终识别和忙碌期排队恢复到 v917 路径。字幕动画没有修改，屏幕共享代码也没有修改。

微信聊天输入框改为 iPhone 不自动放大的 16px，并固定显示在功能／表情面板上方；打开面板时会先收起键盘，避免光标跑到输入框下面或表情面板盖住输入栏。

## 安装

1. 在 Mac 解压后，直接打开 `PhoneCompanionTest.xcodeproj`。
2. Xcode 顶部运行目标选择 `PhoneCompanionTest`，设备选择已连接的真实 iPhone。
3. 运行覆盖安装，不要只复制 Swift 文件。

## 真机重点验收

- 不开启屏幕共享，分别打一通普通电话和普通视频，确认角色首次及连续回复都有声音。
- 免提说话后，确认角色能收到并出声回复；安静时观察是否会产生误发。
- 核对字幕动画仍是安装前确认的当前效果，没有逐字动画改动。
- 微信输入框第一次点击光标就在框内；打开功能和表情面板后输入栏仍可见、可点击、可发送。

Windows 只能完成网页与 Xcode 工程静态回归，不能代替 Mac 六 Target 编译、签名以及真实 iPhone 的 AVAudioSession、麦克风、Speech 和键盘验收。

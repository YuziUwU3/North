# 第三十三次安装：v909／私人 1.0.33 (33)

本包修复两条后台核心链路，并补充 iOS 26 系统闹钟。查看当前软件时，服务器现在读取 Screen Time 子快照自己的真实采集时间，不再因为外层时间为空而误报“没有看清”。角色后台消息必须先完整写入角色聊天并落盘，成功后才向服务器确认，避免通知已经出现、点进聊天却没有消息。

私人版闹钟已接入 iOS 26 AlarmKit。第一次新增或同步闹钟时请允许“小手机使用系统闹钟”；允许后，即使小手机退到后台，闹钟也由 iPhone 系统按时持续提醒。一次闹钟、每日闹钟、关闭和删除都会同步。它是系统闹钟，不是伪装成微信来电；网页和 Android 保留原来的前台闹钟，不受苹果专用改动影响。

宠物睡眠锚点再次按实际房间背景向下校正，落在左侧星星旁粉色垫子内部，不再停在窝顶。

在 Mac 解压后直接打开 `PhoneCompanionTest.xcodeproj`，选择主 Target `PhoneCompanionTest` 和真实 iPhone。不要运行 Report、Monitor、Shield 或 RoleNotificationService 扩展，也不要混入旧 PhoneWeb.bundle。

Windows 自动回归 506/506 通过，`phone-role-push` v909 已在线部署。Windows 无法执行 Xcode／Swift 编译，所以首次安装仍需在 Mac 编译全部 Target，并在真实 iPhone 验证 AlarmKit 权限、退后台响铃、软件查看测试以及通知点进聊天后的消息留存。

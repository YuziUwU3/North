# 第八十二次安装：v960 正版视频与粉色图标修复

## 版本

- 网页核心：v960
- 私人 iOS：1.0.82 (82)
- 原生桥：18

## 本次内容

- 放映室新增优酷开放平台搜索与官方播放器；需要在设置中填写本人 Client ID。
- 放映室新增哔哩哔哩官方播放器；可粘贴 BV 号或视频链接。
- 不抓取视频、不下载受保护内容、不绕过会员、地区或版权限制。没有字幕时角色不会假装理解画面。
- 粉色主题更换抖音、线下约会、惊悚抉择三枚图标，并清理透明边缘杂点。
- 去掉头像选择器两侧深色外框；去掉唱片中心白点和封面黑色外圈。
- 保留 v959 的主动消息、后台联系、主题状态条、半透明气泡和四色唱片功能。

## 安装

1. 完整解压到全新目录，不要覆盖旧工程。
2. 打开 `PhoneCompanionTest.xcodeproj`。
3. 执行 `Product → Clean Build Folder`。
4. 选择 `PhoneCompanionTest` Scheme 和真实 iPhone 运行。
5. 设置页确认显示 v960 与私人安装包 1.0.82 (82)。

## 验收边界

Windows 自动测试、资源清单和 ZIP 完整性检查不等于 Mac 编译、签名或真实 iPhone 验收。六个 Target 仍需在 Mac 编译并做真机测试。

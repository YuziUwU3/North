# 小手机私人版第七十二次安装

- 私人 iOS：1.0.72 (72)
- 内置网页核心：v951 · 顶部试验回退与小号忠诚修复
- 原生桥契约：18

本次撤销 v950 之后失败的 iOS 顶部融合试验，不再使用顶部测试参数、`black-translucent` 或独立测试清单。顶部系统区域仍按 iOS 自身行为显示，本版不宣称已经消除该系统区域。

微信小号恢复为独立陌生人身份：角色不会认出主号本人，但仍记得自己的稳定伴侣与关系经历；小号越界时会拒绝并可拉黑。切回主号后，角色会把刚发生的小号联系作为真实事件主动报备一次；后续有新的小号聊天，再报备一次。询问角色自己微信、好友或消息里发生的事情时，不会误走互联网搜索。

## 安装

1. 完整解压本次 ZIP，确认顶层目录为 `SmallPhone_v951_AltAccountLoyaltyFix`。
2. 在 Mac 上只打开该目录中的 `PhoneCompanionTest.xcodeproj`。
3. 清理旧 Build 后重新编译、签名并安装。
4. 安装后进入设置页，确认显示 v951 和 1.0.72 (72)。

Windows 自动测试不能代替 Mac 编译和真实 iPhone 验收。请重点验证：顶部不再比 v950 试验版额外加宽；小号不认识主号；角色拒绝越界；切回主号能看到一次报备。

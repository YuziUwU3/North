当前私人 iOS 候选版：网页核心 v899／原生 1.0.24 (24)。本机真实数据读取与锁定、解锁、限额已通过原生桥在同一个 App 内直连。聊天、通话和共同生活共用全局读取锁与生成代次：读取期间普通回复静默作废，不再出现“模型没有生成／再点一次”的突兀提示；同一轮原生读取完成后只把真实事实交给角色模型，由角色自行决定说什么、说几句以及分一条或多条发送，不再使用固定汇总模板。线下回应失败会明确区分余额或额度、密钥、权限、限流、接口配置、网络超时和模型空输出，且失败不会改动原对话。后台控制器缺失的远端前置迁移 002 已实际补齐，迁移 002–006 已核验在线。云端仅用于远程设备和后台主动联系。维护与未完成真机验收边界见 `docs/maintenance/私人小手机App_唯一总纲.md`。

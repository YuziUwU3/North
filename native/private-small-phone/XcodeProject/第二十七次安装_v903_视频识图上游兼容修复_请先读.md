# 小手机私人 App 第二十七次安装

版本：网页核心 v903／私人 iOS 1.0.27 (27)。

本版修复 v902 引入的定时自动识图回答回归。识图接口本身能够识别画面，但自动识别后的角色聊天请求缺少真正的 user 消息，部分兼容接口会报“上游聊天服务暂时异常”。v903 参考放映厅，把自动取得的当前画面恢复为本轮唯一的 user 事件，同时继续隔离旧聊天，所以用户不开口时角色也能根据画面说话。v901 已经可用的口头让角色看画面链路保持原样。

设备授权同步收紧：第一次使用的邀请码仍保留；设置中的“生成迁移码”“生成备用恢复码”和进入小手机时的代码恢复输入框均已移除。恢复设备和 Safari／Edge 授权合并只允许本人扫脸或指纹，旧版本调用代码兑换接口也会被云端拒绝。

正常聊天、识图接口配置、摄像头、翻转、分钟间隔、主动不限次和其他通话逻辑均未改动。若角色回答阶段仍失败，通话中央不会再显示错误，只在右下角短暂显示“失败”。

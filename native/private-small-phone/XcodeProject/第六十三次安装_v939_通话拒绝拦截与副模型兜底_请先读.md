# 第六十三次安装：v939 通话拒绝拦截与副模型兜底

- 网页核心：v939
- 私人 iOS：1.0.63 (63)
- 原生桥契约：18
- 必须完整解压本次 ZIP，只从全新目录 `SmallPhone_v939_CallFallbackGuard` 打开 `PhoneCompanionTest.xcodeproj`，不要覆盖旧工程。

## 本次变化

1. 普通语音、普通视频、摄像头识图和共享画面通话的模型回复，在显示、写入角色消息及播放前统一检查。
2. 主模型跳出角色、返回结构化拒绝状态或英语模板输出长篇无逐句中文翻译时，只临时切换一次已配置副模型，并显示主、副模型的实际名称。
3. 副模型回复合格后仅播放当前轮，下一轮自动恢复主模型；不会永久修改角色的模型选择。
4. 主、副模型都没有返回合格内容时，只显示明确系统提示，拒绝文字和长篇无翻译英文不会作为角色台词显示或朗读。
5. 短英文名称、短称呼及中文、粤语、日语、韩语不套用新增英文长句检查；“疼、痛、轻一点”不会被当作现实自伤。
6. “停止、停下、不要继续、不玩了、退出扮演”等明确停止信号仍必须立即尊重；明确现实自伤表达不会绕过主模型拒绝去尝试副模型。

## 编译与验收

1. 解压后打开 `PhoneCompanionTest.xcodeproj`，选择 `PhoneCompanionTest` Scheme 与真实 iPhone。
2. 先执行 `Product → Clean Build Folder`，再编译安装。
3. 设置页顶部必须显示“当前已加载：v939 · 通话拒绝拦截与副模型兜底”和“私人安装包 1.0.63 (63)”。
4. 真机分别测试普通语音、普通视频、英文语音模板及副模型未配置／已配置两种情况。
5. Windows 自动测试和静态检查不能代替 Mac 编译、签名及真实 iPhone 的声音、字幕和模型切换验收。

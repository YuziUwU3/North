# 第二十八次安装 v904 请先读

版本：网页核心 v904／私人 iOS 1.0.28 (28)。

本版只修复两个真机回归。偏好设置中的视频自动识图间隔填写 0 后，会立即撤销当前视频通话已经运行的定时器；即使旧回调已经排队，也会在回调和识图入口再次被拦截。口头说“你看一下”等主动识图仍不限次数。

后台主动消息会把每个角色气泡作为一张独立通知卡，直接显示角色昵称和这一句话，不再折叠成“11 个通知”。角色头像同步会等待大容量图片读出真实头像，通知扩展也会等待通信意图处理完成后再提交内容，避免只显示昵称首字。

苹果系统限制：通信通知的头像会被系统裁成圆形，右下角的小手机图标是系统强制显示的 App 来源标识；App 无法把它改成方形或删除。

## Mac 上只做三步

1. 解压到一个全新目录，打开 `PhoneCompanionTest.xcodeproj`，不要覆盖旧工程。
2. 在 Xcode 顶部选择 `PhoneCompanionTest` Scheme 和已连接的真实 iPhone；执行 `Product → Clean Build Folder` 后运行。
3. 真机验证：间隔 0 时等待数分钟不自动识图，但口头要求仍能看；后台主动消息每句话分别显示正文和真实头像。

Windows 已通过 483/483 自动化回归。Windows 不能替代 Xcode 五 Target 编译和真实 iPhone 通知展示验证。

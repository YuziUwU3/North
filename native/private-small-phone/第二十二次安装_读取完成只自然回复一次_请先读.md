# 第二十二次安装：读取完成只自然回复一次

本包版本为网页核心 v897／原生 1.0.22 (22)。请把整个 `SmallPhone_v897_NaturalSingleReadReply` 目录复制到 Mac，直接打开其中的 `PhoneCompanionTest.xcodeproj`，不要再把文件逐个覆盖进旧工程。

本轮修复的是回复时序，不是伪造或删减真实数据：

- 用户说“读取全部”后，角色不会先生成普通聊天回复。
- 顶部横幅会逐项显示当前正在读取的真实类别。
- 所有原生读取器进入成功、不可用或超时终态后，才会生成角色回复。
- 角色只自然回复一次，不再逐条吐出系统报告，也不再把权限、超时等技术诊断当成自己的话。
- 同一条用户消息有独占 pending 键，避免前后两条重复回复。

Mac 安装步骤：

1. 解压整个交付包到一个全新目录。
2. 打开 `PhoneCompanionTest.xcodeproj`。
3. 执行 `Product → Clean Build Folder`。
4. 选择 `PhoneCompanionTest` Scheme 和真实 iPhone 运行。
5. 只发送一次“读取全部数据”，等顶部逐项进度结束，确认角色只自然回复一轮。

Windows 已完成 475 项自动化测试和 Xcode 工程静态结构检查。Windows 不能替代 Mac 编译、签名、HealthKit／DeviceActivityReport 扩展运行及真实后台通知验收。

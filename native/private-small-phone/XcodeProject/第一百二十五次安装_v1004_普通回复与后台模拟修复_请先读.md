# 第一百二十五次安装｜v1004 普通回复与后台模拟修复

版本：网页 v1004；私人 iOS 1.0.125 (125)；原生桥 25。

请把 ZIP 完整解压成全新目录 `SmallPhone_v1004_ReplyBackgroundIsolationRepair`，不要覆盖旧工程目录。只打开该目录中的 `PhoneCompanionTest.xcodeproj`。

本版在 v1003 基础上处理两个真实回复故障，并新增一条可验收的真实后台消息入口：

1. 私人 App 的后台伴生读取不再全局占用普通微信回复；只有当前这条用户消息明确要求查看手机数据时，才等待该消息自己的真实读取结果。
2. 普通微信回复不再继承后台巡检中的心率、位置、电量或屏幕时间上下文，避免私人 App 独有的回复卡住或异常缓慢。
3. 朋友圈评论参考 7 月 30 日的正常行为，改回一次真实模型请求，并设置 45 秒明确截止；失败只显示“角色未回复 · 点此重试”，绝不补写假评论。
4. “设置 → 聊天与媒体”新增“立即模拟后台主动消息”。它会先核验角色后台资料、服务器每分钟任务和 APNs 通知令牌，再把真实测试任务交给服务器和当前模型，不会在本地插入角色消息。
5. 后台主动心率关心、位置与电量检查、低电提醒、失联检查、每日睡眠步数与全部 App 必查、手动解锁发现等能力继续保留；本版只隔离它们与普通聊天的并发所有权。

Mac 验收顺序：

1. 在 Xcode 执行 `Product → Clean Build Folder`，选择 `PhoneCompanionTest` Scheme 和真实 iPhone 编译运行。
2. 先确认设置页显示 v1004 与私人安装包 1.0.125 (125)，然后连续发送两条普通微信消息，确认角色能正常回复。
3. 在角色朋友圈评论一条具体内容；正常时应出现角色真实评论，接口失败或超过 45 秒时应出现可重试入口，不能出现系统补造的评论。
4. 进入“设置 → 聊天与媒体 → 立即模拟后台主动消息”，选择角色并完成核验；确认后 10 秒内退到 iPhone 桌面，等待真实 APNs 角色通知。前台本地出现一条假消息不算通过。
5. 最后复测心率、位置、电量、低电、失联、手动解锁、每日必查和远程操控，确认修复普通回复没有关闭后台伴生能力。

Windows 已完成 JavaScript 语法、版本一致性、专项与 851/851 自动回归。Windows 自动检查不能替代 Mac 编译、Apple 签名和真实 iPhone 验证。若真机仍异常，请保留当时页面、时间、角色、操作顺序和后台状态截图，不要覆盖旧工程。

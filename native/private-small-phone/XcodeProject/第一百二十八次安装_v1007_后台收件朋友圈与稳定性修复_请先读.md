# 第一百二十八次安装：v1007 后台收件、朋友圈与稳定性修复

版本核对：网页 v1007；私人 iOS 1.0.128 (128)；原生桥 25。

请完整解压 `SmallPhone_v1007_BackgroundInboxMomentsStabilityRepair.zip` 到一个全新目录。不要覆盖 v1006 或任何旧工程，也不要把旧工程中的 `PhoneWeb.bundle`、Swift 文件或配置复制进来。

在 Mac 上打开 `PhoneCompanionTest.xcodeproj`，选择 `PhoneCompanionTest` Scheme 和真实 iPhone，先执行 `Product → Clean Build Folder`，再编译安装。若设置页版本不是 v1007／1.0.128 (128)，立即停止，说明打开的不是本次全新工程。

真机按顺序验收：

1. 普通微信文字回复与电话先做冒烟，确认角色正常出字、出声。
2. 微信和朋友圈分别测试正确与异常内心格式，任何内心内容都不能掉到可见正文。
3. 在微信聊出明确上下文后去朋友圈评论，角色应知道当前在评论区并能承接最近私聊；失败只显示重试，不得出现假回复。
4. 在“设置 → 聊天与媒体”立即模拟后台消息，确认通知送达；返回同一角色聊天页，必须看到与通知一致的真实消息且不能重复。
5. 连续切换多个 App、组件页、网页与私人 App，观察页面是否还能点击、是否出现半屏／黑块，并记录机身温度。iPhone 专用降压会保留玻璃颜色和渐变，但不再叠加大量实时背景模糊。
6. 明确让角色读取全部数据时，仍应执行真实 Screen Time／HealthKit；普通状态轮询不应反复触发这些重型读取。

Windows 已完成 865/865 自动回归，独立云迁移和 APNs 函数已部署；这些不能替代本次 Mac 编译、签名和真实 iPhone 验收。

# 第六十二次安装：v938 第二页照片组件与主题布局

- 网页核心：v938
- 私人 iOS：1.0.62 (62)
- 原生桥契约：18
- 必须从压缩包中的全新目录 `SmallPhone_v938_Page2PhotoThemes` 打开工程，不要覆盖任何旧安装目录。

## 本次内容

- 第一页和最底部 Dock 保持原样；只修改第二页。
- 第二页顶部左侧为 2×2 四个普通 App，右侧为一个竖向人物组件；人物组件只上传一个 84×84 圆形头像，不会把整张方图铺满卡片。
- 人物称呼和下面一句话可单独编辑，输入框字号为 16px。
- 中间横向照片组件内有三张独立拍立得；每张都可直接点按上传。三张照片保持原上下高度，只横向放大并以左右倾斜、中间压在上层的方式错位叠放。
- 下方两排各四个普通 App 使用同一网格；第二页共十二个唯一应用，不会生成重复应用或拖拽空位。
- 黑、灰白、粉、蓝四套主题使用完全一致的布局，只改变玻璃与图片色调。
- v937 的音乐完整性、音乐库来电铃声、安卓视频编码诊断与 iOS 26 输入光标修复全部保留。

## 编译与核验

1. 完整解压本次压缩包，不要覆盖旧目录。
2. 打开 `PhoneCompanionTest.xcodeproj`。
3. 执行 `Product → Clean Build Folder`。
4. 用 `PhoneCompanionTest` Scheme 在真机运行。
5. 设置页顶部应显示“当前已加载：v938 · 第二页照片组件与主题布局”和“私人安装包 1.0.62 (62)”。
6. 进入主屏第二页，分别点圆形头像和三张拍立得，确认四个入口都可选择照片；再检查人物称呼和一句话可以保存。
7. 分别切换黑、灰白、粉、蓝主题，确认布局位置完全一致；拖动第二页应用后确认没有重复、消失或卡住。

Windows 不能替代 Mac/Xcode 的签名和真机编译。本次没有修改第一页、Dock、屏保箭头或 iPhone 主屏幕网页底部系统区域，底部区域仍保持 v934 的处理。

# 小手机私人版第七十次安装说明

## 版本

- 私人 iOS：1.0.70 (70)
- 内置网页核心：v948 · 私人App适配整理
- 原生桥契约：18

## 本次改动

- 私人 App 不再显示网页专用的“苹果兼容适配”开关，也不会再套用网页版 iPhone 主屏幕兼容位移。
- 私人 App 的授权页只保留 App 授权与扫脸／指纹入口，不再显示已授权浏览器、Safari／Edge 合并和浏览器专属说明。
- 顶部 iOS 系统状态栏安全区改回纯黑色；这是原生背景色调整，不会尝试删除系统状态栏，也不会把内容塞到 Dynamic Island 下方。
- 网页版的苹果兼容功能继续存在，Android 逻辑不受影响。
- 锁屏下拉箭头只在第一页主页显示；小号交流回到大号后按新增交流段落只报备一次；既有电话、宠物、音乐、第二页组件和云端止损逻辑继续保留。

## Mac 安装步骤

1. 完整解压本次 ZIP，确认顶层目录为 `SmallPhone_v948_PrivateAppCleanup`。
2. 只打开该目录内的 `PhoneCompanionTest.xcodeproj`，不要覆盖或拖进旧工程。
3. 在 Xcode 执行 `Product → Clean Build Folder`。
4. 选择 `PhoneCompanionTest` Scheme 和真实 iPhone，确认 Team、签名与五个 Target 均正常后运行。
5. 安装后进入设置页，确认顶部显示 `v948 · 私人App适配整理` 与 `1.0.70 (70)`。

## 真机重点验收

- 顶部时间、信号、电量区域底色为纯黑，按钮仍可点击，内容没有进入 Dynamic Island 下方。
- 私人 App 设置中没有“苹果兼容适配”；授权页没有浏览器数量与 Safari／Edge 合并，但扫脸／指纹授权可正常使用。
- 网页版仍能使用苹果兼容开关；Android 主屏滑动、拖拽、组件尺寸和 Dock 不发生回归。
- 第一页可见锁屏箭头，第二页及应用内部不可见；微信小号与大号记忆隔离、报备只在有新增交流时触发一次。

Windows 只能完成静态与自动化测试，最终仍须在 Mac 编译、签名并做真机验收。

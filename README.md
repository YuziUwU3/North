# 小手机

当前基线：网页核心 v935／私人 iOS 1.0.59 (59)／原生桥契约 18。设置页会直接显示当前加载的网页核心和私人安装包版本，便于排除旧解压目录、旧 Xcode 缓存或旧安装包。iPhone 主屏幕 Web App 的系统底栏保持 v934 原处理，不再尝试消除、改色或移动网页适配。微信底部输入栏改用正常文档流预留空间上移，并压缩两侧控件占位来扩大中间输入宽度，“让 ta 回”本身不移动也不再被覆盖。角色微信与小手机真人好友/群聊的新消息继续统一播放上一份用户 MP3；微信来电固定为本次用户提供的唯一 MP3，旧的三套内置铃声和音乐库来电选择已移除。双人组件、屏幕共享逐句看和仅主页第一页显示的屏保箭头继续保留。维护与真机验收边界见 `docs/maintenance/私人小手机App_唯一总纲.md`。

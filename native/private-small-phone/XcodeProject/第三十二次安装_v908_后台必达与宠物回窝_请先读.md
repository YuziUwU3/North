# 第三十二次安装：v908／私人 1.0.32 (32)

本包集中修复连续三次失败的后台核心链路：1 分钟后台通知、查看当前软件立即测试，以及角色正在回复或读取设备时退出小手机后的接力与通知。

根因不是测试等待时间，而是私人 App 的后台推送处理器此前只在一个非主入口页面出现时才注册；同时，服务器把这些明确要求执行的任务也交给了允许“保持安静”的主动消息判断。现在处理器在 App 启动时注册，四类显式任务必须生成真实结果，并记录 APNs 状态、apns-id 和设备回执，失败时可以定位卡在哪一步。

宠物睡觉已按物种和同时睡觉数量重新缩放、定位。最多四只宠物都会进入左侧星星旁的粉色窝垫，不再睡在窝顶或窗台，实际页面截图已经检查。

在 Mac 解压后请直接打开 `PhoneCompanionTest.xcodeproj`，选择主 Target `PhoneCompanionTest` 和真实 iPhone。不要运行 Report、Monitor、Shield 或 RoleNotificationService 扩展，也不要混入旧 PhoneWeb.bundle。

Windows 自动回归 503/503 通过；远端迁移 202608130003 和 phone-role-push 已部署。仍需在 Mac 编译全部 Target，并在真实 iPhone 验证普通回桌面、锁屏和后台通知。请注意：如果用户从多任务界面手动强制划掉 App，iOS 不保证静默推送能重新唤醒应用。

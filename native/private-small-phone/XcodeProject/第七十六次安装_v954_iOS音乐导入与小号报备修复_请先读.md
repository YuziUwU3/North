# 第七十六次安装：v954 iOS 音乐导入与小号报备修复

## 本次版本

- 网页核心：v954
- 私人 iOS：1.0.76 (76)
- 原生桥：18

## 本次修复

1. 音乐库把“选择音乐文件”和“选择录屏视频”拆开，iPhone Files 中已有的 MP3、M4A 等音频应可以正常选中。
2. 小号通过微信号添加角色后的第一轮请求补上兼容接口需要的 user 消息，避免首句 HTTP 400。
3. 客服式首句（例如“有什么可以帮你”）会回退为符合角色与陌生人身份的自然开场。
4. 从小号切回主号后，该次联系一定交付一次自然报备；模型失败时也不会丢失事件。
5. 报备只概括“谁联系、聊了什么、角色怎样处理”，不再机械复述“某某：……；我：……”。
6. “刚刚有人给你发消息吗”等私人状态问题不再误触发联网；明确要求查互联网仍按原逻辑执行。

## Mac 安装

1. 解压本次 ZIP，不要覆盖到旧工程目录。
2. 打开 `PhoneCompanionTest.xcodeproj`。
3. Scheme 选择 `PhoneCompanionTest`，设备选择真实 iPhone。
4. 检查 Signing & Capabilities 后编译安装。

## 真机验收

1. 音乐库点“添加歌曲”后选择“选择音乐文件”，确认 MP3/M4A 可点选。
2. 用小号添加角色，确认第一句不是 HTTP 400 或客服式问候。
3. 小号完成聊天后切回主号，确认角色主动报备一次。
4. 问“刚刚有人给你发消息吗”，确认不出现“正在联网查询”。
5. 报备应像正常人概括，不应逐句列出双方原话。

Windows 无法完成 Xcode 编译和 Apple 签名；这些步骤仍需在 Mac 与真实 iPhone 上验收。

# 第八十八次安装：v966 主屏点按与组件稳定

- 网页核心：v966
- 私人 iOS：1.0.88 (88)
- 原生桥：23

本版修复主屏“翻页顺畅但点按非常迟钝、组件有时出现又消失”的共同根因。普通触摸重新交给系统原生点按和滚动，轻微手指位移不再被 12 像素的自定义滑动逻辑提前截走；真正长按进入编辑后，原有拖拽仍正常接管。主屏页面取消可能错误跳过绝对定位内容的屏外绘制优化，三个页面的应用和组件始终参与绘制。角色人设、世界书、记忆、自主功能、媒体共享、后台主动消息、主题、图标和布局没有被改变。

安装时必须完整解压到全新目录 `SmallPhone_v966_HomeTapRenderStable`，不要覆盖旧工程。用 Xcode 打开 `PhoneCompanionTest.xcodeproj`，执行 `Product → Clean Build Folder`，再选择 `PhoneCompanionTest` Scheme 和真实 iPhone 编译安装。设置页应显示 v966 与 1.0.88 (88)。Windows 自动测试和移动端浏览器模拟不代表 Mac 编译、签名或真实 iPhone 长时间点按与组件稳定性已经通过。

# 第一百二十一次安装：v1000 朋友圈互动与角色分类

本次必须作为全新工程安装，不要覆盖旧目录。正确版本为：网页 v1000；私人 iOS 1.0.121 (121)；原生桥 25；工程目录 `SmallPhone_v1000_MomentsInteractionCategories`。

## 安装只做三步

1. 在 Mac 上完整解压压缩包，并只打开全新目录 `SmallPhone_v1000_MomentsInteractionCategories` 内的 `PhoneCompanionTest.xcodeproj`。
2. Xcode 选择 `PhoneCompanionTest` Scheme 和自己的真实 iPhone，执行 `Product → Clean Build Folder`，再编译安装。
3. 打开小手机设置，确认显示“v1000 · 朋友圈互动与角色分类”和“私人安装包 1.0.121 (121)”后，再验收下列项目。

## 本版重点验收

- 角色设置主页面直接显示五个文字分类，“通话与通话记录”单独进入并只显示通话相关设置。
- 朋友圈点赞可直接点上和取消；评论使用页面内输入，角色回复、点赞、评论在我的朋友圈、角色主页与详情页之间保持一致。
- 删除本人朋友圈后，角色资料页和朋友圈详情中的同一条动态同步消失。
- 角色朋友圈使用黑色分框列表，主朋友圈和角色朋友圈底色一致，纯文字动态不显示灰色占位图。
- 给角色发送原图并要求发布时复用该图；只口头要求既有场景配图时允许自主生图，失败自动重试一次，再失败则发布纯文字。

Windows 自动检查不能替代 Mac 编译、签名和真实 iPhone 验收。本包未声称已经完成真机验证。

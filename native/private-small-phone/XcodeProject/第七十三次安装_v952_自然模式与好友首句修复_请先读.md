# 小手机私人版第七十三次安装

- 私人 iOS：1.0.73 (73)
- 内置网页核心：v952 · 自然模式与好友首句修复
- 原生桥契约：18

## 本次修复

1. 好友刚通过后的自动首句不再把“未配置 API”等内部异常显示成角色气泡；生成失败会发出符合新好友关系的本地首句，无需用户先说话。
2. 微信自然模式不再关闭主动消息、主动电话、节日问候、步数与日程追问；心情值、亲密度和自动关系策略仍保持精简。
3. 小号继续作为独立陌生人，角色不能认出是主号本人；小号真实聊天事件会持久保存，切回主号后只报备一次，主号追问时不得否认。
4. 好友申请被拒绝会累计次数，再次申请时换用不同验证语。
5. 微信拉黑角色后，角色可在 20 秒后改用“电话”App联系；拒接或未接时最多总计拨打三次，并承接拉黑前上下文。

## 安装

1. 完整解压本次 ZIP，确认顶层目录为 `SmallPhone_v952_NaturalFriendRecoveryFix`。
2. 在 Mac 上只打开该目录中的 `PhoneCompanionTest.xcodeproj`。
3. 执行 `Product → Clean Build Folder`，选择 `PhoneCompanionTest` Scheme 和真实 iPhone，重新编译、签名并安装。
4. 安装后进入设置页，确认显示 v952 和 1.0.73 (73)。

Windows 自动测试不能替代 Mac 编译和真实 iPhone 验收。请重点测试：新好友第一句话、自然模式下主动功能、小号切回主号的一次性报备、拒绝好友申请后的不同验证语，以及拉黑 20 秒后的电话 App 来电与最多三次重拨。

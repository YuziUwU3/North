请完整解压到全新目录 `SmallPhone_v973_RoleLockBinding`，不要覆盖任何旧工程。用 Xcode 打开 `PhoneCompanionTest.xcodeproj`，先执行 `Product → Clean Build Folder`，再选择 `PhoneCompanionTest` Scheme 和真实 iPhone 编译安装。设置页应显示“v973 · 角色全锁与关联稳定修复”和“1.0.95 (95)”。

本版修复角色只在聊天中说“全部软件锁掉了”，却没有向真实 iPhone 发送命令、后台也没有操作记录的问题。普通线上聊天重新携带真实控制目标和隐藏动作协议；全量锁定／解锁会按当前全部已选 App 的稳定 ID 逐个执行并立即记录。模型漏标签时，明确的已完成自然表述也会补执行；条件句、威胁句和问句不会误触发。设备回执和新快照确认前只能表达“已提交、等待确认”，不得谎称已经锁好。

本版同时修复“关联小手机 App”选择后过一会儿自动消失。界面中的关联、改名、限额和锁定都按稳定 App ID 定位，不再使用轮询后可能过期的数组序号；关联只有在本机持久化成功后才提示完成。若系统快照更新外置标识，程序会在显示名或绑定码唯一对应时迁移关联及锁定意图，无法唯一确认时不会乱绑。

Windows 自动测试只能验证网页、桥接协议与工程结构，不能替代 Mac 上的 Xcode 编译、签名和真实 iPhone 屏蔽页验收。

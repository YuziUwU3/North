# 第九十二次安装：v970 功能事件主动回复修复

- 网页核心：v970
- 私人 iOS：1.0.92 (92)
- 原生桥：23

请完整解压到全新目录 `SmallPhone_v970_FeatureEventDelivery`，不要覆盖任何旧工程。用 Xcode 打开 `PhoneCompanionTest.xcodeproj`，先执行 `Product → Clean Build Folder`，再选择 `PhoneCompanionTest` Scheme 和真实 iPhone 编译安装。设置页应显示 v970 与 1.0.92 (92)。

本次修复的是整条“真实功能事件主动回复”链路，不是只补单个按钮：真实事件不会再被普通主动联系的在线／冷却判断拦住，不会被用户紧接着发出的消息取消，并且会作为当前最新上下文交给模型，避免重复回答已经回应过的旧句。模型没有形成可见消息时只轻量重试一次，不无限重试，也不增加严格内容拦截。

重点覆盖日记首次错密码、查手机连续三次错密码、微信自备注发现、角色登录用户微信退出后的承接、伴生后台权限变化、电话接通方向、拒接、未接与双方挂断。放映、一起听、礼物、外卖、任务、旅行、见面、亲属卡、验证码、陌生号码识破、远程操控等已有功能事件也统一受保护；原有普通主动消息的冷却与自主判断没有删除。

v969 的 Xcode 编译修复、共享媒体人声增益、屏幕共享上下文和逐句翻译、日记收藏与 24 小时规则、通话记录折叠、推特宽松去重全部保留。通话时长显示逻辑没有改动；网页版仍只是隔离真实设备数据，没有删除现有功能；第二页卡片兼容仍按部分设备／WKWebView 合成差异处理，不理解成只有黑色主题。

Windows 已完成 JavaScript 语法、资源同步、版本一致性、功能回归和原生源码静态检查，但不能代替 Mac 的 Xcode 编译、签名与真实 iPhone 验收。请重点实测：修改微信备注后立即聊天、日记第一次错密码、手机密码第三次错误、关闭伴生权限、双方主动拨打与挂断、角色来电未接、共享结束外语翻译、后台媒体与角色人声音量。

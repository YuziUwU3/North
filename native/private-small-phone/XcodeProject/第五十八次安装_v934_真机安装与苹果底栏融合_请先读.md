# 第五十八次安装：v934 / 私人版 1.0.58 (58)

## 这次必须这样安装

1. 只使用本压缩包中的全新目录 `SmallPhone_v934_InstallVerified`，不要覆盖或合并到旧 v933 工程目录。
2. 在 Mac 打开该目录里的 `PhoneCompanionTest.xcodeproj`。
3. 执行 `Product → Clean Build Folder`，选择 `PhoneCompanionTest` Scheme 后再真机运行。
4. 安装后打开小手机设置页，最上方必须看到：
   - `当前已加载：v934 · 真机安装核验与苹果底栏融合`
   - `私人安装包 1.0.58 (58)`
5. 如果版本不是以上两行，就不要继续验收功能；这说明 Xcode 或手机运行的仍是旧包。

## 本次核验内容

- 私人 App 与网页版共同保留双人组件中间的“相恋 X 天”，只在已经绑定情侣空间并设置开始日期后显示。
- 偏好设置的来电铃声可从音乐库选择在线收藏或本地导入歌曲；歌曲失效时自动恢复默认轻响。
- 微信“让 ta 回”按钮位置不变，下面整条输入栏上提 8px，组件间距和左右留白缩小，中间输入框得到更明显的宽度。
- 输入框继续使用原有 36px 高度和 WebKit 键盘避让，不叠加另一套键盘坐标补偿，蓝色输入光标保留在输入框内部。
- 屏保箭头只固定在主页第一页，第二页没有；App 回前台或页面重绘后会重新校正显示状态。
- 私人 App 的屏幕共享“逐句看”按每句完整发言识别一次画面，关闭后恢复原逻辑。
- 角色微信消息、角色群消息、小手机真人好友私聊和真人群聊的新消息统一播放本次提供的 MP3；消息音量继续跟随总音量。来电铃声选择保持独立，不会被替换。
- iPhone 主屏幕网页版的系统外部底栏不再使用错误灰色，而是与玻璃主页底部 `#0a0b0d` 融合；自定义壁纸仍采样壁纸底色。Android 不套用此处理。

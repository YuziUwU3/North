# 第五十六次安装：v932 / 私人版 1.0.56 (56)

日期：2026-08-15

版本：网页版 v932；私人 iOS 1.0.56 (56)；原生桥契约 18。

## 本次修复

- 撤回 v931 将网页画面向 iOS 主屏幕系统栏下方延伸的补偿。网页锁屏底部的手电筒、相机和上滑提示重新完整落在实际可见视口内；私人 App 的底部按钮布局没有改动。
- iOS 新版主屏幕 Web App 的额外底部区域由 WebKit/系统绘制，网页元素无法覆盖。v932 会从主页壁纸底部取样并设置系统栏颜色，使该区域不再固定显示黑色。
- 第一次打开 v932 后，请把主屏幕 Web App 从后台完全划掉，再重新打开一次，让 iOS 刷新缓存的系统栏颜色。不需要删除或重新添加主屏幕图标。
- 苹果兼容开关继续保留。打开时只会在苹果主屏幕 Web App 和私人 iOS App 内抬高锁屏入口小箭头；Android 不使用这些适配类，因此位置和点击逻辑不变。
- 黑、灰白、粉白、蓝白四套玻璃主题共 96 个应用图标加入离线预缓存；图片读取失败时保留线条或 emoji 占位，避免主页出现只剩名称的空位。

## 安装和验收

1. 请解压整个交付目录，不要只覆盖旧工程中的个别文件。
2. 在 Mac 用 Xcode 打开 `PhoneCompanionTest.xcodeproj`，执行 Clean Build Folder 后编译五个 Target。
3. 在真实 iPhone 上打开一次主屏幕网页版，完全划掉后重开，检查底部系统栏与壁纸颜色衔接。
4. 网页检查锁屏底部两个圆形按钮和上滑提示；私人 App 打开“苹果兼容适配”后检查主页顶部锁屏小箭头。
5. Android 检查原有小箭头位置、点击返回锁屏和主页拖动，确认没有回归。
6. 依次切换四套玻璃主题并断网重开，确认应用图标仍可显示；首次缓存尚未完成时，至少应显示图形占位而不能只剩文字。

Windows 只能完成静态和自动化核验，不能替代 Mac 编译、签名与真实 iPhone 系统栏验收。
